PFO1 – Landing de Portafolio

Landing page personal desarrollada con HTML semántico y CSS propio (sin frameworks), como parte de la Práctica de Formación en el Oficio N°1 (PFO1) de la Tecnicatura Superior en Desarrollo de Software – IFTS 29.

El sitio presenta mi nombre y presentación, mis habilidades técnicas, mi formación, una vía de contacto y el enlace a mi perfil de GitHub.

Tecnologías y requisitos técnicos aplicados

-HTML semántico (header, nav, main, footer, section)
-CSS propio, sin frameworks
-Google Fonts: Fraunces (títulos) e Inter (texto)
-Maquetación con Flexbox y Grid combinados
-Diseño responsive (breakpoints para tablet y celular)
-Transiciones y animaciones (hover en botones, links, tarjetas de habilidades y ítems de formación)
-Imagen con atributo alt
-Formulario de contacto con label asociado a cada campo

Decisiones de diseño

-Elegí un estilo editorial, con un fondo oscuro tipo tinta y un acento en dorado mostaza, buscando una identidad visual propia y distinta.
-Combiné una tipografía serif con carácter (Fraunces) para los títulos con una sans-serif legible (Inter) para el texto, un recurso típico del diseño editorial que le da personalidad sin perder claridad.
-La foto de perfil tiene una forma de arco (en vez del clásico círculo), lograda con border-radius asimétrico, para diferenciarse de los portafolios genéricos.
-Organicé los colores con variables CSS (:root) para poder ajustar la paleta completa de forma centralizada.

Uso de imágenes

La foto de perfil es una foto propia, real. Fue procesada con IA (recorte y ajuste de brillo, contraste, saturación y nitidez) para mejorar el encuadre y la iluminación original. El detalle de esta edición está documentado en la sección de uso de IA, más abajo.

Uso de Inteligencia Artificial

Para este trabajo utilicé Claude (Anthropic), con plan gratuito.
-Experiencia previa: estoy de a poco aprendiendo a usar herramientas de IA; este fue uno de mis primeros usos aplicados a un proyecto de código.
-Para qué la usé:
  -Verificar el código HTML y CSS que ya tenía escrito, y corregir errores.
  -Que me sugiriera distintas paletas de colores y direcciones de diseño, entre las que elegí la que más me representaba.
  -Ayuda para lograr efectos visuales puntuales en CSS: la forma de arco de la foto de perfil, el halo decorativo.
  -Edición de mi foto de perfil (recorte y corrección de brillo/contraste/saturación) usando código Python, a partir de la imagen que yo subí.
  -Qué revisé/adapté con criterio propio: decidí qué paleta de colores, forma de foto y tipografía usar entre varias opciones que se me propusieron, pedí ajustes específicos de tamaño y proporción hasta que el resultado me convenció, y revisé que el contenido (nombre, formación, habilidades, textos) fuera fiel a mi información real antes de publicarlo.
